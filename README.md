### ⚡ What is Karfi Defender?

A lightweight, intelligent Web Application Firewall (WAF) that protects websites from:
- SQL Injection
- XSS Attacks
- DDoS / Brute Force
- Malicious Bots

### 🚀 Features (V4)
- Real-time traffic filtering
- IP Blacklisting
- Attack Logger
- Lightweight - runs on phone!

### 📦 Installation


git clone https://github.com/hassankusfa/karfi-defender.git
cd karfi-defender
pip install -r requirements.txt
python karfi_defenderv4.py


### 🔧 Usage

python
from karfi_defenderv4 import KarfiDefender

firewall = KarfiDefender()
firewall.protect("http://your-website.com")
